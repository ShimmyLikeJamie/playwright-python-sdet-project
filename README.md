This is a test suite for the industry standard site https://www.saucelabs.com/ to showcase that I have the needed skills for an SDET position.

A Page Object Model (POM) architecture is used to keep things modular and scalable, and to simply avoid repeating myself.

GitHub actions are used for CI/CD automated test executions.

Used ReqRes to enable user creation via API requests, since sauce labs doesn't have it's own API and account creation via API requests is faster.

API key is securely managed via environment variables and GitHub secrets.
